1추가한 기능

모두 기존 행(row) 구조 위에 옵션 필드만 얹는 방식 — 저장된 템플릿과 호환됩니다.
기능기존변경 후
바코드·QR 정렬가운데 고정 (하드코딩)좌 · 중 · 우 선택 (기본값 중앙 — 기존과 동일)
바코드 폭내용 길이에 따라 자동10~100% 지정 (빈칸이면 기존처럼 자동). 감열 라벨에서 스캔 인식률 조정에 사용
라벨 여백1.2mm 고정0.1mm 단위 조절 — 감열 프린터 개체별 인쇄 오프셋 보정용

2수정한 버그 — 바코드 왼쪽 쏠림 실사용 발견

폭(%)을 지정하면 바코드가 가운데 정렬되지 않고 왼쪽으로 붙던 문제

원인 — 퍼센트 폭을 가진 인라인 SVG에는 크롬이 text-align:center를 적용하지 않습니다. 폭이 "자동"일 때만 가운데가 맞고, 폭을 지정하는 순간 좌측으로 붙었습니다.

수정 — 정렬 방식을 display:block + margin:auto 기반으로 교체했습니다.

3호환성 · 검증

기존 데이터 영향

  • 저장된 라벨 템플릿 — 새 필드(pad/gap/valign/width/mt/textBold)는 없으면 기존 기본값으로 폴백합니다. 기존 템플릿을 열어도 지금까지와 똑같이 출력됩니다.
  • 백엔드 — 템플릿 config가 자유형 JSON으로 저장되는 구조라 routes_api.py 등 서버 코드는 수정하지 않았습니다.
  • 다른 화면 — 라벨(바코드 인쇄) 화면 외 기능은 건드리지 않았습니다.

검증 내역

  • 전체 스크립트 문법 검사 (단일 파일 SPA라 문법 오류 시 전 화면 백지 — 필수 확인)
  • 렌더 로직 단위 테스트 14항목 통과 (정렬·폭·간격·EAN-13 체크섬·수량 확장·레거시 폴백)
  • 브라우저 실동작 확인 — 미리보기 반영, 픽셀 측정(위 표), 하단 숫자 굵게 적용
  • 미검증 — 실물 감열 프린터 출력. 배포 후 매장 라벨 1장 시험 출력 권장

② 서버 SSH 키 등록 협조 요청

앞으로 이런 화면(static/) 개선은 서울쇼룸에서 직접 배포까지 진행하려고 합니다. 매번 실장님 손을 거치지 않아도 되도록 아래 공개키를 등록해주실 수 있을까요?

echo "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEaKF48VrnpGx1t5v9dKS7s54mk7xe/647jWnGxndT9H jongjin-kanzibox-deploy" >> /root/.ssh/authorized_keys
운영 원칙 백엔드(app/*.py)와 DB는 건드리지 않고 화면 위주로만 작업하겠습니다. 배포 전에는 미리 공유드리고, 문제 발생 시 git revert 후 재배포로 즉시 되돌리겠습니다.

※ root 키 공유가 부담되시면 배포 전용 계정을 따로 만들어주셔도 됩니다. 또는 이번 건만 실장님이 배포해주셔도 무방합니다.
