SEOUL COLLECTIVE 스토어 운영 가이드

한국 스토어(원화)와 일본 스토어(엔화)를 매일 운영하는 실무자를 위한 문서입니다. 메뉴 위치와 입력 규칙을 따라 하면 되도록 정리했습니다. 아직 정해지지 않은 정책은 미정으로 표시했습니다. 가격 산식·관리자 접속 정보 등 내부 정보는 이 공유본에서 뺐습니다.

02주문·배송·반품

주문은 관리자 주문 메뉴에서 처리합니다. 결제(PG) 연동 전이라 지금은 테스트 주문만 들어옵니다.

발송 처리

  1. 관리자 주문 → 처리할 주문 선택 → 항목 처리됨으로 표시(주문 처리)
  2. 추적 정보에 송장번호 입력 · 택배사 선택
    일본 택배사 Sagawa (JA) 선택 → 고객 메일에 사가와 조회 링크가 자동으로 붙습니다
    한국 택배사 미정 (정해지면 해당 택배사 선택)
  3. 고객에게 배송 정보 보내기가 켜져 있는지 확인 → 저장
일본 송장번호 한→일 운송 후 일본 도착 시 사가와 송장이 생깁니다. 사가와 송장번호를 받는 방식은 운송사와 확인 중입니다. 받기 전에는 발송 처리를 미뤄 두세요.

고객 문의·리뷰

  • 문의는 각 스토어의 「문의하기 / お問い合わせ」 페이지 양식으로 들어와 회사 메일로 전달됩니다. 평일 10:00~18:00 응대 기준입니다.
  • 리뷰는 앱 → Judge.me Reviews → Reviews에서 확인·숨김 처리합니다. 리뷰가 0개인 상품은 리뷰 영역과 별점이 자동으로 숨겨집니다.

03상품 등록·수정

상품은 원칙적으로 연동 스크립트가 등록합니다. 손으로 등록하거나 고칠 때는 아래 규칙을 지켜야 브랜드 페이지·필터·신상품 목록·상품정보제공고시가 자동으로 맞게 나옵니다.

A. 기본 절차: 연동 스크립트로 일괄 등록

신규 시즌 입고, 여러 상품을 한 번에 올릴 때 씁니다. 실무자 단계와 스크립트 단계가 번갈아 진행됩니다.

단계담당할 일결과물
1. 대상 선별실무자수집 엑셀(브랜드 자사몰 전체 상품)에서 올릴 상품을 표시. 선별 기준은 회의 결정(미정)등록 대상 목록
2. 최신 정보 수집스크립트대상 상품의 정가·옵션(색상·사이즈)·품절·이미지를 자사몰에서 다시 가져옴—
3. 상세정보 추출·번역스크립트상세페이지에서 실측·소재·세탁·제조국·착용감 추출 (글이 없으면 상세 이미지를 AI가 판독) → 일본어 번역—
4. 가격 계산스크립트한국 산식 미정 · 일본 정해진 산식으로 엔화 계산—
5. 검수 엑셀 확인실무자상품명(판촉 문구 제거 여부), 가격, 옵션, 추출된 소재·실측, 일본어 번역을 원문과 대조. 고칠 내용을 엑셀에 표시검수 완료 엑셀
6. 초안 등록스크립트두 스토어에 초안 상태로 등록: 이미지, 옵션, 가격, 재고, 브랜드·유형·태그, 상품정보제공고시, 통관 정보(일본)스토어 초안 상품
7. 화면 확인·보완실무자관리자에서 초안 상품을 열어 이미지 순서 확인, 바이어 코멘트 입력, 필요하면 랭킹 컬렉션에 추가—
8. 판매 시작실무자상태를 활성으로, 판매 채널 「온라인 스토어」 켜기 → 스토어에서 노출 확인판매 중
9. 정기 갱신스크립트자사몰 정가·품절 변동을 주기적으로 반영 (주기 미정)—

B. 한두 개만 직접 등록할 때 (관리자)

  1. 제품 → 제품 추가
  2. 제목 입력 (한국: 한국어, 일본: 일본어). 「[1+1 할인]」 같은 판촉 문구와 색상명은 제목에서 빼고 옵션으로
  3. 미디어에 이미지 업로드 (세로 3:4, 첫 장 정면컷)
  4. 설명: 실측표·소재·세탁·제조국·착용감만 (05장 원칙)
  5. 가격 입력 (03장 가격 규칙)
  6. 재고: 「수량 추적」 켜고 수량 입력
  7. 변형: 옵션 추가 → 이름은 한국 「색상」「사이즈」 / 일본 「カラー」「サイズ」 → 값 입력 → 변형별 가격·재고 확인
  8. 일본 변형의 배송 항목에 무게, 원산지(대한민국), HS 코드 입력
  9. 제품 구성: 유형, 공급업체(브랜드), 태그 2026FW
  10. 맨 아래 메타필드: 바이어 코멘트 / (한국) 소재·제조국·세탁방법·제조연월 / (일본) 日本サイズ目安
  11. 검색 엔진 목록: 제목 「상품명 | SEOUL COLLECTIVE」 형식
  12. 상태 초안으로 저장 → 미리보기 확인 → 활성 + 판매 채널 「온라인 스토어」 켜기
한국·일본 둘 다 판매하는 상품 직접 등록할 때는 두 스토어에 각각 등록해야 합니다. 상품이 많으면 A 절차로 스크립트에 맡기는 편이 정확하고 빠릅니다.

문구 작성 규칙

한국

  • 고객 안내 문장: 해요체 (「교환·반품은 7일 안에 신청할 수 있어요.」)
  • 버튼·라벨: 명사형 (「장바구니 담기」, 「주문하기」, 「신상품 보기」)
  • 브랜드 소개: 명사형 종결 (「…구조적인 실루엣.」) — 「선보여요」 같은 해요체 금지
  • 「카트」 대신 「장바구니」, 「품목」 대신 「상품」

일본

  • 가격은 총액 표시(税込·関税込み)가 원칙. 표기 문구는 관세 부담 방식이 정해지면 다시 확인
  • 사이즈 용어: 着丈·肩幅·身幅·袖丈 등 일본 EC 표기
  • 配送: 「日本国内は佐川急便がお届けします」
쓰지 않는 표현 근거 없는 최상급(「최고」, 「유일」), 확인되지 않은 효능·인기 주장, 브랜드가 쓰지 않은 소재·원산지 정보.

06테마 수정 규칙

디자인·구조 수정은 게시 중인 테마에서 직접 하지 않습니다. 실수해도 바로 되돌릴 수 있게 복제본에서 작업합니다.

  1. 온라인 스토어 → 테마 → 게시 테마 「…」 → 복제 (이름 끝 버전 번호를 하나 올림. 예: KR v6 → KR v7)
  2. 복제본에서 수정 (스크립트 작업도 항상 복제본에)
  3. 미리보기로 PC·모바일 확인 (홈, 상품 상세, 목록, 장바구니)
  4. 문제없으면 복제본 게시. 직전 테마는 백업으로 하나만 남기고 그 이전 버전은 정리

09오픈 전 남은 일

결정이 필요한 것 (회의 안건)

  • 일본 스토어 주소 (jp.seoulcollective.kr 또는 seoulcollective.jp)
  • 한국 판매가 산식 (정가 그대로 / 별도 산식 / 세일 연동)
  • 한국 택배사·배송비·반품비
  • 일본 관세·소비세 부담 방식 (당사 부담 DDP / 고객 부담 DDU) — 물류비 견적 포함 여부 확인
  • 환율 기준과 엔화 끝자리 처리
  • 등록 상품 선별 기준, 엑셉턴스레터 원화 정가
  • 판매 명의 확정, 한국·일본 PG 계약

결정 후 진행 순서

  1. 상품 20개 시험 등록 → 검수 (가격·번역·상세정보)
  2. 선별 상품 전체 등록 (초안으로 검수 후 활성)
  3. 【 】 칸 채우기, 반품배송비 엔화 금액·사업자 정보 반영
  4. PG 연동 → 테스트 결제
  5. 일본 스토어를 정식 전환 가능한 스토어로 이전 → 두 스토어 정식 전환(Basic 요금제)
  6. 도메인 연결, 발신 메일 인증, 견본 상품 삭제 → 오픈

10Claude에게 맡기기

Claude는 두 스토어에 API로 연결되어 있어서 반복 작업과 일괄 수정을 대신할 수 있습니다. 담당 PC의 작업 폴더에서 Claude를 열고 아래처럼 말로 요청하면 됩니다.

분야맡길 수 있는 일요청 예시
상품브랜드 자사몰 상품 수집, 가격 계산, 상세정보(실측·소재·세탁·제조국) 추출과 일본어 번역, 두 스토어 일괄 등록·수정, 정가·품절 갱신, 견본 상품 정리「카미노 신상품 10개 수집해서 검수 엑셀 만들어줘」
「검수 끝난 엑셀대로 두 스토어에 초안 등록해줘」
재고·주문재고 수량 일괄 변경, 주문 목록·매출 요약, 발송 처리(송장번호 일괄 입력), 할인 코드 만들기「이번 주 주문 요약해줘」
「이 엑셀의 송장번호로 일본 주문 발송 처리해줘」
컬렉션·검색컬렉션 조건 정리, 태그·상품 유형 일괄 수정, 검색 결과 제목·설명 일괄 작성, 색상 계열 정리「브랜드명이 잘못 들어간 상품 찾아서 고쳐줘」
페이지·문구안내 페이지·메뉴 작성과 수정(한국어·일본어), 카피 검토, 브랜드 소개, 【 】 칸 일괄 채우기「배송비 3,000원으로 정해졌어. 관련 문구 전부 바꿔줘」
디자인테마 복제본에서 화면 수정·섹션 추가, PC·모바일 화면 점검, 어색한 곳 찾아 제안「상품 상세 모바일 화면 점검하고 고칠 점 알려줘」
문서·조사회의자료·보고서·이 가이드 갱신, 결제·관세·물류 조사, 엑셀 정리「회의 결정 내용 반영해서 가이드 갱신해줘」
